> Chirograph is being extracted from LaunchPad's MSBuild SDK and has no release yet. These docs are a placeholder until the first beta.

A chirograph was a medieval contract written twice on one sheet and cut apart, so each half proved the other. Here the OpenAPI
document and the generated client are the two halves.
